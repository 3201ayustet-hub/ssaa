# 日本全国陣取り MVP

スマートフォン優先のPWA実装です。ZIP直下はこのフォルダ1階層のみです。

## 実装済み
- 日本47都道府県SVGを主役にしたマップ
- 4人のプレイヤー登録・色・居住県
- ゲーム開始
- 旅行記録、証拠写真1枚、確認画面
- 登録後は履歴からテスト記録を削除可能
- 最新有効滞在による所有権判定
- 同日競合はブランク
- 居住県は全員共通で対象外
- プレイヤー詳細ボトムシート
- 期間ポイントの簡易算出
- 管理者ページ、ポイント設定、決着履歴
- iPhoneホーム画面追加用PWA manifest/service worker

## 地図について
都道府県形状は Geolonia の `japanese-prefectures` のモバイルSVGを利用しています。README記載のライセンスはGFDLです。実装時は利用条件・配布条件を確認してください。

## 起動
静的ファイルをHTTPSで配信してください。ローカルでは任意の静的HTTPサーバーで `index.html` を開きます。

例:
`python3 -m http.server 8080`

その後 iPhone Safari からアクセスし、「ホーム画面に追加」でPWAとして利用できます。

## 本番化で置き換える箇所
現在はブラウザのlocalStorageを使用しています。Supabase本番版では games / players / stays / point_transactions / settlements 等へ接続し、Storageへ写真を保存、RLSと管理操作の制御を追加してください。

## 今回の改善実装

- 旅行登録画面の写真選択をiPhoneで確実に反映するよう修正
- 写真選択後に画面全体を再描画せず、登録確認ボタンをその場で有効化
- 写真を保存前に縮小・JPEG化して、スマートフォンでの保存容量を抑制
- 地図上の都道府県タップから「この県の旅行を記録」へ直接進める導線を追加
- 地図から登録した場合は都道府県をあらかじめ選択
- 登録確認データを安全に一時保持し、確認後の登録処理を安定化
- 地方境界について、既存の都道府県SVGの県境線を利用して該当境界を太く表示
- テスト用の旅行記録削除機能は維持
