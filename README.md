# 日本全国陣取り MVP

スマートフォン向け旅行・都道府県陣取りゲームのMVPです。

## 今回の仕様
- ゲーム開始ボタンはありません。プレイヤー情報を保存した時点で、未設定なら記録開始日を自動設定します。
- 地図上の都道府県をタップして旅行登録へ進めます。
- 通常の「記録」画面からも登録できます。
- 写真を選択すると確認ボタンが有効になります。
- 登録済み旅行記録は履歴から個別削除できます。
- プレイヤー名・居住県・色を変更できます。
- 地方制覇は地図下とプレイヤー詳細に表示します。
- シーズン終了では、滞在履歴・所有県・地方制覇を維持し、今期ポイントだけを0にして次シーズンへ進みます。
- 累積ポイントと決着履歴は維持します。
- 「ゲームデータをすべて削除」で開発・テスト用に初期状態へ戻せます。

## 地図
Geolonia の日本都道府県SVGを利用しています。実運用ではSVGをローカル同梱し、ネットワーク障害時にも地図を表示できるようにすることを推奨します。

## 注意
このMVPはブラウザのlocalStorageを使う単体テスト版です。Supabase本番接続、認証/RLS、Storage、月次ジョブなどは本番化工程で実装してください。
