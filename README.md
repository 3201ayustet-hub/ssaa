# 日本全国陣取りゲーム v1.2
iPhoneからGitHubへ入れやすいよう、配布ZIPの直下に全ファイルを配置しています。

## 起動
`index.html` をWebサーバーで公開してください。

## v1.2
- 47都道府県データ
- 4人プレイヤー
- 滞在登録
- 都道府県の所有状態表示
- 所有数・ポイント集計
- iPhone向けレスポンシブUI
- LocalStorageによる簡易保存
