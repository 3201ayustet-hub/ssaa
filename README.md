# SSA 語句群穴埋め演習

セーフティサブアセッサ（SSA）学科試験向けの、文章・表の語句群穴埋め演習アプリです。

## 収録内容

- 91問題セット
- ISO 12100 / JIS B 9700
- ISO 13849-1 / JIS B 9705-1
- IEC 60204-1 / JIS B 9960-1
- ISO 13854, ISO 13855, ISO 13857
- ガード、インターロック、非常停止、文書化、関連法令の基礎

## 方針

- 学習履歴、ログイン、苦手分析は実装しない
- 条文・定義・表の穴埋めを中心にする
- 問題ごとに短い解説と参照規格を表示する
- 問題順と語句群をランダム化する
- データ整合性をビルド前に自動検査する

本アプリは公式過去問題集ではありません。日本認証が公開する出題範囲・問題形式と主要規格の要点を基に、学習用として独自に再構成しています。規格本文の逐語転載ではありません。

## ローカル実行

```bash
npm install
npm run dev
```

## 検査とビルド

```bash
npm run validate
npm run build
```

## GitHub Pages

1. このフォルダをGitHubリポジトリへpushします。
2. `npm install && npm run build` を実行します。
3. `dist` をGitHub Pagesへ公開します。

GitHub Actionsを使う場合は、同梱の `.github/workflows/deploy.yml` を利用できます。

## 問題追加

`src/data/questions.json` に問題を追加します。ビルド時に次を検査します。

- ID重複
- 空欄と正答の対応
- 正答が語句群に存在すること
- 必須項目
- 語句群の重複
